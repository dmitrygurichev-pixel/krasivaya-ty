# Студия автопортрета: камера → обработка → Яндекс Диск

Работает без участия человека: следит за снимками с камеры, прогоняет каждый через цепочку обработки из
`config.yaml` и выкладывает на Яндекс Диск в папку по дате. Всё на бесплатных инструментах:
Python, Pillow, requests, PyYAML, SQLite, REST API Яндекс Диска (и, по желанию, gphoto2).

```
камера ──► inbox/ ──► обработка (Pillow) ──► Яндекс Диск /Автопортрет/2026-10-13/20261013_142501_IMG_0042_color.jpg (и _bw.jpg)
             ▲                                  ▲
   папка или gphoto2             очередь в SQLite: повторы при обрыве интернета, переживает перезагрузку
```

## Надёжность
- **Нет интернета / ошибка Диска** — снимок остаётся в очереди, выгрузка повторяется с паузой до 5 мин, бесконечно.
- **Перезагрузка ПК** — очередь в `data/jobs.sqlite`, ничего не теряется и не выгружается дважды.
- **Недозаписанный файл** — ждём `stable_seconds`, битые файлы после 3 попыток уходят в `data/failed/`.
- **Обрыв камеры** (режим gphoto2) — процесс перезапускается автоматически.
- Оригиналы после выгрузки лежат в `data/archive/`; лог — `data/logs/studio.log` (с ротацией).

## Установка
```bash
cd selfportrait-studio
python -m venv .venv && . .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp config.example.yaml config.yaml
```

### 2. Камера Canon EOS 90D на Windows
Режим `folder`: камера подключена к ПК кабелем USB, программа съёмки сохраняет каждый кадр в `C:\Studio\inbox`.
- **Canon EOS Utility 3** (бесплатно с сайта Canon): *Дистанционная съёмка* → *Настройки* → *Папка назначения* = `C:\Studio\inbox`;
  включить «Сохранять только на ПК» или «ПК и карта».
- Либо **digiCamControl** (бесплатно, поддерживает 90D): Session → Folder = `C:\Studio\inbox`; есть таймер/триггер съёмки.
- Формат снимков: **JPEG** (L, Fine). RAW+JPEG тоже подойдёт: `.cr3` игнорируются, берётся JPEG.
- Питание камеры от сетевого адаптера (муляж батареи), автовыключение камеры — Выкл., USB-кабель короткий и без хабов.
- Спуск: пульт/кнопка клиента или таймер — программа не вмешивается, она подхватывает любой новый файл.

### 3. Алгоритм обработки
Секция `processing.variants` — по одному файлу на вариант. Сейчас два: **color** (`..._color.jpg`) и **bw** (`..._bw.jpg`).
Они подобраны под ваши эталоны «до/после» (замеры по пикселям: расхождение цветного с вашим 18 → 6 из 255,
ч/б 13 → 8.6): тени и середина светлее, тёплые тона (волосы, кожа) ярче, лёгкий локальный контраст и резкость;
ч/б — с упором на красный канал, чтобы кожа была светлой. Остаётся небольшая разница: ваши эталоны, похоже,
сделаны с ручной локальной ретушью, и цвет волос у них чуть насыщеннее.

Шаги применяются сверху вниз; параметры правятся в `config.yaml` без программирования:

| op | параметры |
|---|---|
| `curve` | `points: [[вход, выход], ...]` для всех каналов или отдельно `r`, `g`, `b` (значения 0–255) |
| `warm_boost` | `gamma` (осветление тёплых тонов), `saturation`, `center`/`width` (диапазон оттенков) |
| `gray_mix` | `weights: [r, g, b]` — ч/б с выбором вклада каналов |
| `unsharp` | `radius`, `percent` (маленький радиус — резкость, ~8 — локальный контраст) |
| `crop_ratio` | `ratio: "4:5"` — центральная обрезка |
| `autocontrast` | `cutoff` (%) |
| `brightness` `contrast` `color` `sharpness` | `factor` (1.0 — без изменений) |
| `grayscale` | — |
| `resize` | `max_side` (только уменьшение) |
| `border` | `size`, `color` |
| `watermark` | `path` (PNG), `position`, `scale`, `margin`, `opacity` |

Один вариант: оставьте в `variants` одну запись с `name: ""` — суффикса в имени не будет.
Поворот по EXIF применяется автоматически. Оригинал уходит в архив только после выгрузки всех вариантов.

### 4. Запуск
```bash
python -m studio --once      # один проход: проверка
python -m studio             # постоянная работа
```
Автозапуск: `deploy/selfportrait.service` (Linux, systemd) или `deploy/windows_autostart.md` (Windows).
На ПК студии отключите сон, автообновление с перезагрузкой в рабочие часы и поставьте автологин/службу.
