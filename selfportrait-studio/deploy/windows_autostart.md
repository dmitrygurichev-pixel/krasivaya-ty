# Windows: автозапуск без входа пользователя

1. `setx YADISK_TOKEN "ваш_токен" /M` (от администратора) — или положите токен в `token.txt` и укажите `token_file`.
2. Планировщик заданий → Создать задачу:
   - Триггер: «При запуске компьютера»; «Выполнять независимо от входа пользователя».
   - Действие: программа `C:\selfportrait-studio\.venv\Scripts\python.exe`, аргументы `-m studio -c config.yaml`,
     рабочая папка `C:\selfportrait-studio`.
   - Параметры: «Перезапускать при сбое каждые 1 минуту», снять «Останавливать задачу, выполняемую дольше…».
3. В электропитании отключите сон и отключение USB-портов.
